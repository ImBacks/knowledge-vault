# knowledge-vault · 收录知识库

给 AI 助手（Claude Code / ZCode 等支持 SKILL 的 agent）用的个人知识库技能：把「现在觉得有用、还不知道何时会用到」的工具和知识收进一个私人候选池，**做项目之前回来检索有没有能用上的**。

- **索引单文件**（`大纲.md`：目录 + 条目行），长正文外置 `知识/` 一条一文件，检索分级下钻不全量读——索引体积只随条数增长，可支撑百万条（SQLite + FTS5 派生索引）。
- **引用可核验**：正文引用一律指向原件 + 页码/时间戳（`【p12】`/`[00:12:34]`），OCR/转写内容标「据识别」，推断标「（推断）」。
- **内置 material-parser 子模块**加速大文件：PDF/EPUB 解析（文本层 + OCR 兜底）、视频/B站/抖音解析（CC→AI 字幕→本地转写三级链路 + 场景检测/讲述锚点双信号关键帧），内容寻址缓存 + 断点续跑。
- **skill 是死的、AI 是活的**：技能提供杠杆（任务分发表、按视频类型可选的解析开关），类型判断交给调用方 agent。

## 项目亮点

这个仓库既是一个能日常使用的 AI 技能，也是一份**为 LLM 设计数据格式、流程与工具的工程样本**。以下每一条都有实物可查，欢迎按图索骥：

- **AI 原生的信息架构**：单文件索引（`大纲.md`）+ 长正文外置（`知识/`），索引体积只随条数增长、不随内容长度增长——这是大库能存在的前提，也是防 LLM 上下文爆炸的根本设计。规模路径预先推演到位（700 条分片 / 千条上 FTS5 / 百万档预案，见 `详细/体检与规模.md`），什么时候换什么工具是算术题，不是玄学。

- **为 agent 写的运行手册**：SKILL.md 是可版本化的 agent 指令层——991 行手册（SKILL.md＋`详细/` 十模块）按「检索会话零额外载入」做模块化路由，§ 编号跨文件稳定引用；「skill 是死的、AI 是活的」原则给 agent 划出裁量空间与不可裁量的底线；v3→v35 的每次修订全部留痕（每条规则为什么存在、是哪次审查暴露的问题）。

- **LLM 与传统工具的分工设计**：自动化不迷信——大文件按**成本比**决策（工具路线快 2 倍以上才值得走脚本，阈值表只是预计算答案）；机械部分归脚本（OCR 断点续跑、缓存键、编译校验），判断归 agent（材料分型、解析开关裁剪）；每条自动化都有明写的降级链路（依赖缺席 → 先提议 → 降级直读/手工），工具缺席永不卡死流程。

- **多会话并发正确性**：租期制文件写锁（令牌释放、自动过期、锁内重验锚点与去重）解决多个 agent 会话并发写同一文件的 read-modify-write 竞态；写后自检脚本保证结构硬错误当场清零；派生索引（SQLite + FTS5）永远可重建、主文件唯一真相，检索入口用前自动比对 mtime——**绝不查陈旧索引**（假阴性 = 漏检 = 最贵的失败）。

- **防幻觉的证据链**：留证不留档（逐字引用 + 页码/时间戳指向原件）、推断与 OCR/转写内容强制标注、`活`/`核` 双日期把「最近被用过」与「最近被核实」解耦、本地校验与联网核验严格分离、抽查护栏（单次 ≤5 条、距上次 ≥30 天）——为「AI 收藏的东西半年后还可信」设计的完整纪律。

- **中文检索与缓存工程**：作用短语按「将来会搜的词」预切分（切分粒度 = 检索粒度，上倒排索引不用回头改全库数据）、别名池治召回、FTS5 + LIKE 子串兜底；内容寻址缓存（sha1 键 + 参数级命中 + 断点续跑 + 运行锁判活 + 免重哈希索引）让几 GB 视频的重复解析秒回。

- **测试纪律**：111 项合成数据自测（4 个库级脚本 53 项 + 解析子模块 58 项），覆盖写锁全路径、导入分诊、陈旧索引回归、无音轨容错这类真实踩过的坑；约定「改任一脚本必跑全量再收工」。约 4300 行 Python，四个库级脚本零第三方依赖。

## 安装

1. 把 `knowledge-vault/` 目录整个复制进你的技能目录（或任意位置）。
2. **库根定位**：技能默认从自身位置向上找 `大纲.md` 定位库根；装在库根之外时设环境变量 `MATERIAL_PARSER_CACHE=<库根>/解析缓存`（详见 `knowledge-vault/SKILL.md` 配置节）。
3. **依赖全部可选**：用真实 Python 解释器跑 `material-parser/scripts/common.py --doctor`，按用途报缺哪些并给精确安装命令（完整清单见下方「工具清单」）。注意 Windows 商店版 `python` 是占位 stub 跑不起来——用实际安装路径，本机约定见 `knowledge-vault/SKILL.md` 配置节。不装也能用——agent 直接读原件，慢一些。
4. **自检**：`python knowledge-vault/scripts/selftest.py`（四个库级脚本全合成数据自检，不碰真实库、不联网）；`python knowledge-vault/material-parser/scripts/selftest.py` 验解析子模块——后者需先能定位缓存根（在库根目录下运行，或设 `MATERIAL_PARSER_CACHE`），否则会按设计报错退出。

## 工具清单：默认与可选

**默认（开箱即用，零 pip 依赖）**

- 技能本体 + 四个库级脚本（体检 / 派生索引 / 写锁 / 导入分诊），只用 Python 标准库；
- 大文件由 agent 直读原件——慢速但全流程可用；
- `common.py --doctor` 环境自检（只读）：报缓存根、逐项依赖、ffmpeg、GPU 三态。

**可选 · 按用途装（装哪组看你收什么，`--doctor` 给精确命令）**

| 组 | 装什么 | 解锁能力 | 代价 |
|---|---|---|---|
| A · PDF / EPUB | pymupdf、rapidocr、Pillow、numpy | 文本层秒级直提、扫描页 OCR、章节分块、断点续跑 | 纯 pip，分钟级 |
| B · 转写 | faster-whisper、av（另装 ffmpeg） | 音视频转文字（VAD 过滤、分块、断点续跑） | 模型首跑下载 ≈500MB（走 hf-mirror） |
| C · 在线视频 | yt-dlp | CC/AI 字幕秒级拉取，多数情况不用下载视频本体 | 纯 pip |
| D · 蒸馏 | pyyaml（可选 tiktoken、jsonschema） | 长内容蒸馏（`distill/` 子模块 = cangjie-skill：书籍/课程/长会话转写 → 方法论与可执行技能包，七阶段 agent 执行、脚本编译校验） | 纯 pip，秒级 |
| 关键帧 | （随 A/B 组） | 双信号抽帧（场景检测 + 讲述锚点）+ 缩略图对照表 | ffmpeg 一装（`winget install Gyan.FFmpeg`） |

**可选 · GPU 转写加速（默认 CPU，功能完全一致，只影响速度）**

- **收益**（实测参考：RTX 5060 + small 模型，140 秒中文音频）：CPU 21 秒 / GPU 7 秒（约 3 倍；CUDA kernel 首跑有预热）。不同硬件与模型收益不同，不承诺固定倍数，跑一次即知；模型越大、视频越长，差距越大。
- **开启**：`python -m pip install nvidia-cublas-cu12 nvidia-cudnn-cu12`（约 1.5GB，要求 N 卡驱动支持 CUDA 12、ctranslate2 ≥4.5），解析时加 `--device cuda`；`--doctor` 显示 ✅ 即就绪。
- **约束**：不装不影响任何功能；显式点名 cuda 而环境不可用 → 报错退出，不静默回落；换设备沿用已转写缓存（要重转加 `--force`）；小显存卡（≤8GB）跑大模型（medium+）先小规模验证。

## 目录

```
knowledge-vault/
├── SKILL.md        技能本体（任务分发 + 常驻核心：开局 / 模式 / 检索 / 降级安全 / 日志检索侧）
├── 详细/            流程与分型细则模块，按需读、检索会话零模块：
│                     收录主流程 · 写入协议 · 维护 · 素材处理 · 条目格式与正文 · 视频 · 图片 · 文档 · 体检与规模 · 导入合并
├── material-parser/ 素材加工子模块：解析（PDF/OCR/转写/关键帧）＋ 蒸馏（distill/ = cangjie-skill 功能子集）
├── scripts/         check_outline 体检 · build_index 派生索引 · write_lock 写锁 · merge_outline 导入
└── 变更记录.md       开发史
```

库的数据文件（`大纲.md`、`日志.md`、`知识/` 等）由使用者自建于自己的库根，**不在本仓库内**。

**Obsidian 适配**：库根可直接用 Obsidian 作为 vault 打开——`知识/` 一条一文件、条目间 `- 相关：[[双链]]` 互链，图谱与反向链接开箱即用（人类侧视图；AI 侧仍走 `大纲.md` 索引与脚本）。建议把 `解析缓存/`、`索引/` 加进 Obsidian 的排除目录（Settings → Files & Links → Excluded files），避免缓存文件进图谱和搜索。
