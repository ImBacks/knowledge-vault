# 视频收录细则（knowledge-vault 详细模块）

> **何时读：收录视频 / B站 / 抖音 / 直播录像动笔前。**
> 解析工具的用法与开关见 `../material-parser/解析手册.md`（不在此重复）；主流程在 `收录.md` §4，落盘走 `写入协议.md` §7。

## 视频

- **有音频或字幕**：转文字再抽取。长视频只抽「明确推荐 / 演示过」的对象，跳过广告与寒暄。一个长视频讲一个方法论 → 1 条知识条目 + 1 个正文文件，时间点做成二级标题。
- **无音频，或用户说「看看这是什么」**：看画面——界面里的软件名、URL、按钮文字、操作流程。
- **解析开关按视频类型裁（杠杆见 material-parser 手册「命令」节；工具不替人分类，判断交给 agent）**：纯口播 → 默认转写即可，不开 `--keyframes`（画面不解码，零浪费）；无口播/纯画面+背景乐 → `--no-transcribe --keyframes`（跳过转写只抽帧）；讲述+展示混合（讲义/教程/录屏直播/举物讲解）→ `--keyframes`——场景检测抓翻页/切屏，**讲述锚点**抓「看这个/如图/手上」这类话指向画面而画面没变的瞬间；超长幻灯片 → `--max-frames 300` 放宽封顶；指物用词特殊 → `--cue-words 锅,焊点` 换词表。转写 0 段时脚本会提示纯画面路线。
- **主动核验（必做，发挥能动性）**：视频没念出链接时，两条路都要走——
  1. 按条目名字联网搜索仓库 / 官网（名字可能被口播念错，多试几个变体，如口播 Impossible 实为 impeccable）；
  2. 逐帧看画面：URL、仓库界面、弹幕/字幕里出现的链接都提取出来。
  - 搜到的地址必须与视频内容对得上（名字一致、作用吻合）才采用；采用自行搜到的仓库时，备注注明「仓库为自行核验」。
  - 对不上或搜不到 → 来源写视频出处，作用末尾标 `（待补充）`，不硬凑。
