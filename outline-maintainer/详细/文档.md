# PDF / EPUB 收录细则（outline-maintainer 详细模块）

> **何时读：收录 PDF / EPUB 动笔前。** 解析工具见 `../material-parser/解析手册.md`；主流程在 SKILL.md §4–§7。

## PDF / EPUB

1. **先看有没有文本层**。有 → 直接抽文本。没有（扫描件）→ 读图，全文标 `（据扫描件识别，可能有误）`。
2. **先出目录再决定收哪几章**。超过 30 页的 PDF / EPUB，先给用户一份章节清单 + 建议收录范围，不要整本塞进去。用户说「全收」才全收。
3. **图表和数字单独复核**。PDF 里的表格、图表数值最容易看错。引用具体数字时必须能指到页码；跨页表格拼接不确定的，宁可写「原文表格跨页，具体数值未核清」。
4. **一本书 / 一份大 PDF / EPUB = 1 条知识条目 + 1 个正文文件**，章节做二级标题。不要每章建一条。
5. **留证不留档**（§16）：正文里留逐字引用 + 页码/时间点，**默认不复制原件**。只有孤本、或用户明确要求，才把原件放进 `素材/`。
