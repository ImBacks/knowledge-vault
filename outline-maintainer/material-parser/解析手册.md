# 素材解析手册（material-parser · 内置可选模块）

版本：v1.8（2026-10-25）。本文件是 outline-maintainer 技能内置子模块 `material-parser/` 的**使用手册（不是技能，不注册、不触发）**；模块位置 `<技能目录>/material-parser/`，命令均在本目录下执行。Python 路径约定同 outline-maintainer 配置节。

## 何时用（与 outline-maintainer §9 衔接）

- **大文件**：>30 页的 PDF / EPUB、>10 分钟的音视频 → 先跑本工具解析，读产物而非原件。阈值的本质是**成本比**：工具路线（解析+读产物）比 agent 直读快 2 倍以上才算大文件，判据与阈值表见 outline-maintainer §9。
- **小文件直接读原件更快**，不必走解析（解析+读产物两步反而慢）。
- 产物在 `<库根>/解析缓存/<文件名>-<sha1前10位>/`，**随时可整目录删除重建**，删了不丢任何源数据。**定位是收录期间的工作台，不是档案：入库落盘成功后即删**（outline-maintainer §7 第 9 条驱动；手动删用 `common.py --clean <目录>`，未完成任务会拒删保断点）。

## 铁律

1. **引用一律指向原文件 + 页码/时间戳**，禁止把 `解析缓存/` 路径写进任何知识条目或正文——缓存可删，引用不能悬空。chunk 内自带 `【p12】`/`[00:12:34]` 标记，直接引用标记对应的原件位置。
2. **OCR / 转写文本属「据识别」**：引用前按页码/时间戳回查，入库时标 `（据识别，可能有误）`（outline-maintainer §9 通用铁律）。
3. **转写默认 small 模型**，中文专有名词/术语错误率不低；要更准用 `--model medium`（约 2 倍时长）。事实性引用（数字、人名、链接）必须回查后才能落库。
4. **长任务后台跑**：几小时视频的转写在 CPU 上要几十分钟，用后台任务执行，不要阻塞会话。

## 命令

```
D:\python\python.exe scripts/parse_pdf.py <pdf/epub> [--chunk-pages 50] [--dpi 150] [--no-ocr] [--force]
D:\python\python.exe scripts/parse_video.py <视频/音频路径或URL> [--model small] [--language zh]
    [--chunk-sec 600] [--keyframes] [--no-transcribe] [--max-frames 120] [--cue-words 词1,词2]
    [--keep-audio] [--cookies chrome|edge] [--force]
D:\python\python.exe scripts/common.py --clean <缓存目录> [--force]   # 入库后清理：done 才删，未完成拒删保断点
```

- **parse_pdf（PDF / EPUB，fitz 兼容格式 xps/mobi/cbz 同样可试）**：文本层秒级直提；文本薄的页（<25 字符/页）逐页 RapidOCR 兜底（CPU 约 1~2 秒/页，逐页断点）。有书签按章节分块，无书签每 50 页一块。概览.md 自带章节表（满足「>30 页先出章节表」）。
- **parse_video** 在线视频三级链路：①CC 字幕（免登录秒级）→ ②AI 字幕（`--cookies chrome`，浏览器需已登录）→ ③下载音频本地转写兜底。本地视频/音频直接转写。`--keyframes` 抽关键帧+缩略图对照表，**双信号**：场景检测抓画面突变（翻页/切屏/镜头切换）；**讲述锚点**抓「话指向画面」的瞬间——转写/字幕命中"看这个界面/如图/手上"类用语即在该时间戳抽帧，举物讲解、指屏幕角落这类**画面没变**的时刻只有锚点能抓到。锚点优先保预算、场景帧均匀填充、±3 秒去重，封顶 `--max-frames`（默认 120）；在线拉流封顶 1080p（缩略图足够）。
- **在线视频站点**：yt-dlp 支持的均可（B站/抖音/TikTok/YouTube 等），三级链路同样适用。抖音类预期：基本无 CC/AI 字幕、确定落兜底转写（十几分钟视频 CPU 转写 5~10 分钟），部分内容需 `--cookies`；取不到视频信息时自动退回按 URL 成键，不会卡死。
- **按材料类型选开关（AI 裁量，不是硬规则——工具提供杠杆，类型判断交给调用方）**：纯口播（信息在讲述里，画面只是人在说话）→ 默认即可，不加 `--keyframes`（画面根本不解码）；无口播/纯画面+背景乐（幻灯片、录屏展示）→ `--no-transcribe --keyframes`（跳过字幕与转写）；讲述+展示混合（讲义、教程、举物讲解、录屏直播）→ `--keyframes`；超长幻灯片录像 → `--max-frames 300` 放宽封顶；指物用词特殊（做菜/手工/电路）→ `--cue-words 锅,面团,焊点` 换词表（空串禁用锚定）。转写结果 0 段时脚本会提示纯画面路线；纯画面缓存重跑去掉 `--no-transcribe` 自动补转写。

## 产物结构

```
解析缓存/<名>-<sha1前10>/
├── 概览.md        # 先读这个：章节表/时间范围、chunk 索引、关键帧表
├── chunks/        # 分块正文，按需读对应块，别全读
├── manifest.json  # 参数、进度、chunk 清单（机器用）
├── transcript.srt / segments.jsonl   # 视频类
├── keyframes/     # --keyframes 时：kf_NNNN.jpg + contact.jpg 拼图
└── lock.pid       # 任务运行期间存在
```

**AI 读法**：先读概览定位 → 再读 1–3 个相关 chunk → 引用时用 chunk 里的页码/时间戳标记指向原件。三级下钻，不要全量读 chunks。

## 缓存语义

- **缓存根定位（三级）**：`--cache-root` 参数 > `MATERIAL_PARSER_CACHE` 环境变量 > 脚本向上找 `大纲.md` 自动定位库根（`<库根>/解析缓存`，模块嵌在技能目录任意深度都能找到）。三级都落空 → **运行时报错**要求显式指定，绝不静默把缓存建到陌生位置。技能装在库根之外（如技能目录且库根不在上层）时，向上找不到库根，必须设环境变量或传参。`--doctor` 会报缓存根及其来源。
- **按 sha1 查找缓存**：文件改名不失效（manifest 记 aliases）；URL 优先按「站点+视频ID」成键（短链/参数变体同一视频共用缓存，B站分 P 单独成键），取不到视频信息时退回规范化 URL 串。重跑同一本地文件时走缓存根级 `sha1-index.json`（记 源路径→size/mtime/sha1）：未变即免整文件重哈希——几 GB 视频的"秒回"不再被 10 秒/GB 的 sha1 拖住；索引只是提示，不匹配就重算。
- **命中条件**：status=done 且参数一致（PDF：chunk-pages/dpi/OCR 开关；视频转写路线：model/language）。参数不匹配 = 不命中，重跑流程——但**慢步骤按参数复用**：OCR 逐页复用（改分块不重识别），转写在 model/language 未变时复用（改 chunk-sec 只重新分块），keyframes 是叠加产物、缺了单独补不重转写（`--max-frames` 变化会重抽帧；`--cue-words` 换词需 `--force`）。纯画面（visual）路线的缓存，重跑去掉 `--no-transcribe` 自动补转写。manifest 的 `transcribe_done` 标记转写已完成：即使产物被手动删，重跑也只按现有段落重建，不重下音频。
- **运行锁 lock.pid**：同目录已有活进程 → 拒绝运行并提示，指路是「另一会话正在解析同一材料：不要换参数或 `--force` 强跑，等它结束后重跑同一条命令即命中缓存秒回」；进程已死 → 自动清理陈旧锁续跑（`--clean` 同样判活，陈旧锁不再永远挡住清理）。长任务后台跑时避免并发重跑同一文件。多会话解析**不同**材料互不影响（各材料独立缓存目录）；同一材料的重复解析由「缓存键 + 运行锁」收敛为一次解析、其余等待复用。
- **断点续跑**：中断（kill/断电）后重跑同一命令自动续——PDF 按 OCR 页、视频按转写段落落盘，已完成的单位不重做。
- **中间文件生命周期**：转写成功后中间 wav/下载的媒体默认删除（几小时视频是 GB 级）；中断时保留供续跑；`--keep-audio` 强制保留。
- **缓存生命周期：工作台，不是档案**。收录落盘成功后即删（outline-maintainer §7 驱动，或手动 `--clean`）；**唯一例外：在线视频走转写路线的产物保留**——库内无原件，缓存转写是唯一本地文本记录（重拉要几十分钟）。未完成任务的缓存是断点，`--clean` 拒绝删除（`--force` 才删）。

## 环境

- 安装依赖（**可选，按用途**，不必全装）：`D:\python\python.exe -m pip install -r requirements.txt` 装全；只想解析 PDF 就只装 requirements.txt 里 A 组。
- ffmpeg 缺失时：`winget install Gyan.FFmpeg`（先征得用户同意），装完重开终端。
- whisper 模型下载默认走 hf-mirror（脚本内置 HF_ENDPOINT，可用环境变量覆盖）。
- 自检：`D:\python\python.exe scripts/common.py --doctor`——依赖/ffmpeg/GPU 探测，并**按用途报告**（「要转写还缺什么 + 精确 pip 命令」）。检测到 NVIDIA GPU 时提示「有加速潜力，但需额外安装 CUDA/cuDNN 运行库并配 PATH」——不是改一行参数的事，默认仍按 CPU int8。
- 自测：`D:\python\python.exe scripts/selftest.py`（合成数据全链路，不依赖真实素材；需能定位到库根或已设 MATERIAL_PARSER_CACHE）。
