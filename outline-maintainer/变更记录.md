# 变更记录（outline-maintainer 开发史）

## v3 变更（相对 v2）

| 变更 | 位置 | 原因 |
|---|---|---|
| 条目分两类：工具条目 / 知识条目 | §3 | v2 只有一种格式，`作用 ≤ 60 字` 装不下长内容，长摘要被 §14 禁止，导致知识类材料无处可放 |
| 知识条目长正文外置到 `知识/` 独立文件 | §15 | 索引体积只随"条数"增长，不随"内容长度"增长。这是大库能存在的前提 |
| 原文留存：留证不留档 | §16 | 多模态提取会失真，必须能回头核；但整份存原件会撑爆磁盘，所以留逐字引用 + 页码，默认不复制原件（v8 修正） |
| 检索改为分级下钻 | §5 | 全量读正文在几百条以上不可行 |
| 新增操作日志 | §17 | 记录"为什么收录 / 为什么跳过"，是复盘判断的唯一依据。git 只记文件状态 |
| 新增体检 | §18 | 原脚本只查数量一致性，不管内容健康度 |
| 新增规模与分片规则 | §19 | 明确什么量级做什么动作，什么时候才允许上向量库 |
| 脚本扩展为自检 + 体检 | 内置脚本 | 支持正文文件存在性、主键重复、旧 `范围` 字段未迁移、单条子类等检查 |
